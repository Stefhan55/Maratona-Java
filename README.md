☕ Maratona Java - DevDojo
Bem-vindo ao meu repositório de estudos da Maratona Java do DevDojo (ministrada pelo William Suane)! 🚀

Este espaço é dedicado ao meu regresso aos estudos e à modernização das minhas competências de programação. Estou a utilizar este curso para recomeçar após um período de paragem, consolidando a lógica de programação, reforçando os conceitos fundamentais de Java e explorando recursos modernos com o JDK 21.

🎯 Objetivos do Repositório
🔄 Retoma e Reforço: Reconstruir a base sólida de Orientação a Objetos (OO) e lógica.

🚀 Modernização: Praticar o código tirando partido da versão LTS mais recente (Java 21).

📝 Prática Constante: Escrever código à mão, linha por linha, para fixar o aprendizado e evitar o falso aprendizado.

🏗️ Evolução Contínua: Servir de trampolim para os meus estudos focados em concursos públicos na área de TI.

🛠️ Tecnologias e Ferramentas Utilizadas
☕ Linguagem: Java (JDK 21 LTS)

💻 IDE: IntelliJ IDEA

🎓 Curso Base: Maratona Java (DevDojo)
